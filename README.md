# Paveworks Solutions

High-performance landing page for **Paveworks Solutions** — commercial asphalt paving, luxury architectural interlocking pavers, concrete flatwork, and sealcoating services across Florida.

## Tech Stack
- **Framework**: [Next.js](https://nextjs.org/) (App Router, Static Export)
- **Styling**: Modern CSS System with Manrope typography and Paveworks architectural color palette
- **Deployment**: Vercel & GitHub

## Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
